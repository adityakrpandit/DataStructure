# Data Structure Using C

This repository contains practical programs for **Data Structure Using C (05BC3302)** as part of the Bachelor of Computer Applications (BCA), Semester 3, at Marwadi University.

## Course Information

- **Course:** Data Structure Using C
- **Subject Code:** 05BC3302
- **Semester:** 3
- **Programming Language:** C
- **University:** Marwadi University

## Units Covered

### Unit 1: Introduction to Data Structure

This unit covers the fundamentals of data structures, arrays, and basic operations on data.

**Practical Topics:**

* Introduction to Data Structures
* Types of Data Structures
* Linear and Non-Linear Data Structures
* Arrays and their operations
* Searching in Arrays
* Insertion and Deletion
* Array Traversal
* Sorting Techniques
* Merging Arrays
* Matrix Operations

**Concepts:** Data types, primitive and non-primitive data structures, time complexity, space complexity, and algorithm analysis.

### Unit 2: Stack and Queue

This unit focuses on linear data structures and their operations and applications.

**Practical Topics:**
* Introduction to Stack
* Stack Operations: Push, Pop, Peek, Peep and Change
* Stack Implementation using Arrays
* Applications of Stack
* Recursion and Stack
* Factorial using Stack and Recursion
* String Reversal using Stack
* Power Calculation using Stack
* Introduction to Queue
* Queue Operations: Insert, Delete and Display
* Simple Queue Implementation

**Concepts:** Stack operations, recursion, applications of stacks, Polish notation, queues, and queue operations.

### Unit 3: Linked List

This unit covers dynamic data structures and linked list operations.

**Practical Topics:**
* Singly Linked List
* Doubly Linked List

**Concepts:** Linked list creation, node manipulation, traversal, insertion, deletion, singly linked lists, and doubly linked lists.

### Unit 4: Trees

This unit introduces tree data structures and tree traversal techniques.

**Practical Topics:**
*  Binary Tree
*  Binary Search Tree

**Concepts:** Tree terminology, binary trees, array and linked representations, tree traversal, conversion of general trees to binary trees, and Binary Search Trees.

### Unit 5: Graphs

This unit covers graph representation and traversal algorithms.

**Practical Topics:**
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

**Concepts:** Graph terminology, adjacency matrix, adjacency list, BFS, and DFS traversal.

## How to Run the Programs

1. Clone or download this repository.
2. Open **Code::Blocks IDE**.
3. Navigate to the required unit folder and open the `.c` file.
4. Click **Build and Run** or press **F9** to compile and execute the program.
5. Enter the required input and view the output in the console window.
